# 🚀 Bootcamp Kick — Projetos e Desafios

Este repositório reúne os projetos, desafios, exercícios e materiais desenvolvidos por **Pedro Yokada** durante o Bootcamp Kick. A proposta é preservar a evolução do aprendizado em um único lugar, mantendo os trabalhos originais organizados por etapa e tecnologia.

> **Importante:** os repositórios originais permanecem preservados. Esta consolidação foi organizada sem a intenção de apagar versões anteriores dos projetos.

## 📚 Sobre o Bootcamp

Os projetos deste repositório representam uma trajetória prática que começou com fundamentos de HTML e CSS, passou por prototipação no Figma, responsividade, JavaScript, consumo de APIs, Bootstrap, um projeto web completo, WordPress e chegou a Python e análise de dados.

## 📈 Evolução durante o Bootcamp

Os primeiros trabalhos registram a prática de estruturação de páginas, tabelas e estilização. Na sequência, os exercícios passam a envolver prototipação, identidade visual e responsividade. Depois, JavaScript é incorporado para criar funções, decisões, repetição, quizzes, formulários, consumo de API e componentes dinâmicos.

A evolução culmina no **Projeto Web Xbox**, desenvolvido desde a prototipação no Figma até sua implementação em HTML, CSS e JavaScript. Os módulos finais expandem o repertório para WordPress e Python, incluindo exercícios de programação e um projeto de análise de dados.
