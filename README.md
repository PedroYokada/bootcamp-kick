# 🚀 Bootcamp Kick — Projetos e Desafios

Repositório consolidado com os **projetos, desafios, exercícios e materiais** desenvolvidos por **Pedro Yokada** durante o Bootcamp Kick. O objetivo é apresentar a evolução do aprendizado em um único lugar, com uma estrutura organizada por área, links diretos para os projetos e preservação dos trabalhos originais.

🔗 **Acesso ao repositório:** https://github.com/PedroYokada/bootcamp-kick

> Os repositórios originais continuam preservados. A consolidação foi feita para organizar o portfólio sem apagar a trajetória de desenvolvimento de cada projeto.

## 📚 Sobre o Bootcamp

A jornada registrada aqui passa por fundamentos de desenvolvimento web, HTML e CSS, prototipação no Figma, responsividade, JavaScript, consumo de APIs, Bootstrap, desenvolvimento de um projeto web completo, WordPress e Python com análise de dados.

### ℹ️ Por que alguns itens pareciam estar faltando?

Eles **existiam no repositório**, mas estavam agrupados dentro dos READMEs de **WordPress** e **Python** em vez de aparecerem individualmente no README principal. Isso acontecia principalmente porque esses materiais vieram originalmente de repositórios únicos contendo várias paradas e desafios internos.

Além disso:

- algumas pastas internas não possuem README próprio;
- algumas são atividades incompletas, mas foram preservadas por valor histórico;
- algumas pastas são apenas telas ou assets de um projeto maior e não devem ser tratadas como projetos independentes;
- existem cópias idênticas de algumas atividades iniciais, então o índice evita duplicar o mesmo conteúdo como se fossem projetos diferentes.

## 🗂️ Organização do repositório

Os diretórios utilizados para organizar a consolidação seguem **kebab-case**: palavras em letras minúsculas separadas por hífen. Essa convenção deixa nomes e URLs mais legíveis e consistentes.

```text
bootcamp-kick/

│
├── javascript-front-end/
│   ├── desafio-19-kick/
│   ├── desafio-22-kick/
│   ├── desafio-23-kick/
│   ├── desafio-25-kick/
│   ├── desafio-27-kick/
│   ├── desafio-29-kick/
│   ├── desafio-31-kick/
│   └── parada-34-kick/
│
├── projeto-xbox/
│   ├── projeto-xbox-figma/
│   └── projeto-xbox-web/

├── wordpress/

```

> A padronização em kebab-case foi aplicada à estrutura principal criada durante a consolidação. Pastas internas dos projetos antigos podem manter seus nomes originais quando a alteração poderia quebrar caminhos, referências ou prejudicar a preservação histórica.

## 📈 Evolução durante o Bootcamp

Os primeiros trabalhos registram a prática de estruturação de páginas, tabelas e estilização. Na sequência, os projetos avançam para prototipação, identidade visual, responsividade e construção de interfaces mais completas. O JavaScript passa a ser utilizado em funções, estruturas de decisão, repetição, quizzes, formulários, depuração, consumo de APIs e componentes dinâmicos.

O **Projeto Xbox** reúne duas etapas importantes da formação: planejamento visual no Figma e implementação em HTML, CSS e JavaScript. Os módulos seguintes ampliam a experiência para WordPress e Python, incluindo notebooks e análise de dados.

## 🧾 Preservação dos projetos

A consolidação foi realizada com `git subtree` sem `--squash`, preservando os históricos incorporados durante a migração. Projetos com arquivos de mesmo nome permanecem isolados em suas próprias pastas, evitando sobrescritas.

Nenhum repositório antigo foi excluído durante este processo.
