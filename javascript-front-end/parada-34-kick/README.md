## 🧠 Conceito presente

O trecho existente pratica uma das formas mais básicas de estilização em CSS:

```css
body {
  background-color: blue;
}
```

**`body`** é o seletor aplicado ao corpo da página e **`background-color`** define sua cor de fundo.

Essa regra só produzirá efeito visual quando houver uma página HTML carregando o arquivo CSS. No estado atual preservado, não existe conteúdo implementado no HTML.
